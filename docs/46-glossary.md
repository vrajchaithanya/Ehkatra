# 46 — Glossary
Status: Living · Arbiter of ubiquitous language (drifted terms fail review)

**Grid Platform** — the product family name (working). **USK** — Universal Spreadsheet Kernel, the `no_std` Rust core. **PAL** — Platform Abstraction Layer, the 10-trait OS seam. **Op** — immutable, causally-ordered unit of change; the only mutation primitive. **Group** — atomic set of ops from one Command; unit of undo, audit, and attribution. **Command** — user/API/agent intent; compiled to ops once, at the authoring replica, by the **Reducer** (pure, versioned). **Watermark** — a causal version point in the op log. **Tile** — 256×64-cell storage/sync/cache unit. **Promotion** — escalation of a tile from summary to per-cell CRDT metadata under true concurrency. **Identity / ordinal** — permanent RowId/ColId vs. its current display position; **A1 is a view**. **Interval** — identity-space range; the reference primitive. **Formula group** — one shared formula pattern over a region; a dep-graph node. **Spill** — derived overlay occupied by a dynamic-array result; never stored cells. **Materialize** — writing a volatile/external result into the CRDT as an attributed value. **Calculation Authority** — the single executor for T3/external/iterative evaluation. **Profile** — `compat` (Excel behavior incl. enumerated bugs) vs `native`. **Container** — the SQLite working file on desktop; XLSX is **interchange**. **Snapshot** — content-addressed compacted state image; **compaction** — snapshot + rewriter + tombstone GC past the 180-day **staleness window**. **Retain-losers** — keeping the losing concurrent register write 30 days for conflict surfacing. **Blast radius** — cell-count/impact threshold triggering preview/approval policy for agents. **Taint record** — the logged set of data an AI action read. **Oracle corpus** — Excel-captured input→output vectors; the conformance spec. **Replay bundle** — op-log slice + state hash; a deterministic bug reproduction. **Evidence tag** — `measured(link)` or `target(assumption-id)` on every quantitative claim.
